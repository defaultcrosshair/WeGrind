## ✨ Features

- 🗂️ **Interactive Flashcards**: Master complex concepts with ease using our fluid, gesture-friendly flashcard system.
- 🎮 **Space Shooter Learning**: A unique gamified experience that makes studying addictive and fun.
- 🏆 **Global Leaderboard**: Compete with peers and climb the ranks as you master your subjects.
- 📊 **Progress Tracking**: Visualize your growth with dynamic progress rings and detailed statistics.
- 📚 **Resource Library**: Instant access to curated study materials, notes, and references.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/defaultcrosshair/WeGrind.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## 🛠️ Built With

- **Frontend**: React 19, Vite, Lucide React
- **Styling**: Vanilla CSS with modern Glassmorphism aesthetics
- **Animations**: GSAP (GreenSock Animation Platform)
- **Backend/Hosting**: Firebase
